# Sesión 2. Envejecimiento y reforma pensional

**Propósito:** Analizar el envejecimiento poblacional y sus implicaciones para el sistema pensional colombiano.

## Agenda (4 horas)

| Bloque | Duración |
|---|---|
| Marco conceptual | 1 h |
| Taller práctico | 2 h |
| Discusión del caso y lecturas | 1 h |

## Contenidos

### Envejecimiento demográfico

- Cambios en la estructura por edad
- Razones de dependencia
- Esperanza de vida a los 65 años

### Sistema pensional

- Relación cotizantes / pensionados proyectada
- La reforma pensional (Ley 2381 de 2024)
- Economía generacional y transferencias
