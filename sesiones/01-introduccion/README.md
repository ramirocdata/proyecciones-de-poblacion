# Sesión 01. Qué es proyectar una población

## Objetivos

- Diferenciar proyección, pronóstico y prospectiva.
- Plantear la ecuación compensadora P(t+n) = P(t) + B − D + I − E.
- Reconocer las fuentes de datos demográficos en Colombia.

## Taller

Con totales agregados (nacimientos, defunciones, migración), completar la ecuación compensadora y calcular tasas brutas.
